--- layout: default title: "bundle remove" description: "Removes gems from the Gemfile" url: /bundler-reference/bundle-remove permalink: /bundler-reference/bundle-remove/ previous: /bundler-reference/bundle-pristine next: /bundler-reference/bundle-show --- Removes gems from the Gemfile 
`bundle remove [GEM [GEM ...]]

Description

Removes the given gems from the Gemfile while ensuring that the resulting Gemfile is still valid. If a gem cannot be removed, a warning is printed. If a gem is already absent from the Gemfile, and error is raised.

Example:

bundle remove rails

bundle remove rails rack
