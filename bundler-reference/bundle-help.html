--- layout: default title: "bundle help" description: "Displays detailed help for each subcommand" url: /bundler-reference/bundle-help permalink: /bundler-reference/bundle-help/ previous: /bundler-reference/bundle-gem next: /bundler-reference/bundle-info --- Displays detailed help for each subcommand 
bundle help [COMMAND]

Description

Displays detailed help for the given subcommand. You can specify a single COMMAND at the same time. When COMMAND is omitted, help for help command will be displayed.
