<em class="text-neutral-600">What each `bundle` command does, and how to use it.</em>

This reference was automatically generated from Bundler version 4.0.17.

## Primary Commands

* [bundle](/bundler-reference/bundle/) - Ruby Dependency Management
* [bundle install](/bundler-reference/bundle-install/) - Install the dependencies specified in your Gemfile
* [bundle update](/bundler-reference/bundle-update/) - Update your gems to the latest available versions
* [bundle cache](/bundler-reference/bundle-cache/) - Package your needed .gem files into your application
* [bundle exec](/bundler-reference/bundle-exec/) - Execute a command in the context of the bundle
* [bundle config](/bundler-reference/bundle-config/) - Set bundler configuration options
* [bundle help](/bundler-reference/bundle-help/) - Displays detailed help for each subcommand

## Utilities

* [bundle add](/bundler-reference/bundle-add/) - Add gem to the Gemfile and run bundle install
* [bundle binstubs](/bundler-reference/bundle-binstubs/) - Install the binstubs of the listed gems
* [bundle check](/bundler-reference/bundle-check/) - Verifies if dependencies are satisfied by installed gems
* [bundle clean](/bundler-reference/bundle-clean/) - Cleans up unused gems in your bundler directory
* [bundle console](/bundler-reference/bundle-console/) - Open an IRB session with the bundle pre-loaded
* [bundle doctor](/bundler-reference/bundle-doctor/) - Checks the bundle for common problems
* [bundle env](/bundler-reference/bundle-env/) - Print information about the environment Bundler is running under
* [bundle fund](/bundler-reference/bundle-fund/) - Lists information about gems seeking funding assistance
* [bundle gem](/bundler-reference/bundle-gem/) - Generate a project skeleton for creating a rubygem
* [bundle info](/bundler-reference/bundle-info/) - Show information for the given gem in your bundle
* [bundle init](/bundler-reference/bundle-init/) - Generates a Gemfile into the current working directory
* [bundle issue](/bundler-reference/bundle-issue/) - Get help reporting Bundler issues
* [bundle licenses](/bundler-reference/bundle-licenses/) - Print the license of all gems in the bundle
* [bundle list](/bundler-reference/bundle-list/) - List all the gems in the bundle
* [bundle lock](/bundler-reference/bundle-lock/) - Creates / Updates a lockfile without installing
* [bundle open](/bundler-reference/bundle-open/) - Opens the source directory for a gem in your bundle
* [bundle outdated](/bundler-reference/bundle-outdated/) - List installed gems with newer versions available
* [bundle platform](/bundler-reference/bundle-platform/) - Displays platform compatibility information
* [bundle plugin](/bundler-reference/bundle-plugin/) - Manage Bundler plugins
* [bundle pristine](/bundler-reference/bundle-pristine/) - Restores installed gems to their pristine condition
* [bundle remove](/bundler-reference/bundle-remove/) - Removes gems from the Gemfile
* [bundle show](/bundler-reference/bundle-show/) - Shows all the gems in your bundle, or the path to a gem
* [bundle version](/bundler-reference/bundle-version/) - Prints Bundler version information
